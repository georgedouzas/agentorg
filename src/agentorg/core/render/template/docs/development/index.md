# Development

## Environment setup

This project uses [uv](https://docs.astral.sh/uv/) to manage dependencies and [nox](https://nox.thea.codes/en/stable/) to run development tasks. To setup the development environment you can follow the next steps:

- Install [uv](https://docs.astral.sh/uv/getting-started/installation/).

- Fork and clone the repository.

- `uv sync` from the root of the project to install the main and development dependencies.
